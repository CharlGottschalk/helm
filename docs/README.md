# Helm user guides

Helm is a local Command Deck for ThisDamnThing (TDT) workspaces. It shows a dashboard
of widgets, tabbed tools, a brain graph, agent sessions and a workspace terminal. Helm
never runs a model itself. It hands chat and builds off to Claude Code or Codex.

Helm is in **beta**. Its features and configuration can change between releases.

## Start here

1. [Getting started](getting-started.md): install Helm, add a workspace and start it.
2. [Configuration](configuration.md): `~/.helm/config.json`, workspaces, profiles and
   hosts.
